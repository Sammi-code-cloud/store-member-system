# 员工微信绑定

1. 管理后台新增员工，填写手机号、门店和角色。
2. 保存后展示专属二维码；也可以从员工列表点击“绑定微信”重新生成。
3. 员工使用本人微信扫码，输入后台登记的手机号并确认绑定。
4. 绑定后可用微信登录。首页在“我的会员账户”下方显示员工工作台，仅具有 `dashboard:view` 权限且身份有效的员工可见。

二维码有效期 10 分钟且仅可使用一次，刷新会使旧码失效。它具有账号绑定授权作用，只应交给对应员工。员工停用、手机号不符或身份冲突时拒绝绑定。

小程序必须包含扫码入口页面。体验版需要在微信公众平台设置体验版本并添加体验成员；正式版发布后，服务器将员工码环境配置为 `release`，再生成新二维码。

员工绑定微信会同步会员档案；已有同一微信的会员保留原余额和记录。系统不根据手动输入的手机号自动合并其他会员钱包。
