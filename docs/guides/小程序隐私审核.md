# 小程序隐私审核

代码提供《用户服务协议》《隐私政策》完整阅读页、登录前主动同意、会员资金敏感信息单独同意、微信原生隐私授权、预约通知逐次单独同意，以及个人中心查看和撤回授权入口。

## 构建配置

在忽略的 `.env.local` 和 `.env.production.local` 设置真实的公开运营主体全称、隐私联系电话和通信地址，字段见小程序 `.env.example`。主体证件、密钥和服务密码不得提交 Git。页面展示的资料与微信平台信息须一致。更改处理目的、方式、范围时更新授权版本。

## 微信公众平台

代码上传不修改平台“用户隐私保护指引”。运营者须在平台检查并补齐当前版本真实收集/使用的类型和目的：微信标识用于账户识别与绑定；手机号与短信验证用于身份核验、会员联系；姓名/称呼用于显示及预约联系；会员余额与交易记录用于记账、查询和对账；预约资料用于门店排期与联系；相机扫码用于员工识别业务凭证；订阅消息为另行允许的提醒。

填写真实运营主体、公开隐私电话和联系方式，以及腾讯微信、阿里云服务器/短信、WxPusher预约通知的实际用途、涉及信息和接收对象。拒绝预约通知的信息提供时可电话预约。公众平台提供的字段须按实际功能选择，不为未使用的能力申请授权。

## 审核复现步骤

1. 清除本小程序缓存后打开首页：公开浏览可用，未主动调用微信登录，不上传个人资料。
2. 进入会员登录：两项同意均默认未选；打开协议和政策能阅读全文，关闭后仍未授权。
3. 未勾选时点击登录：不取得微信凭证、不发送个人请求。明确勾选后，平台需要授权时继续通过微信原生隐私同意按钮；拒绝不会登录。
4. 同意后执行正常登录或短信绑定。短信只在本人主动发起验证时发送。
5. 预约确认页另有默认未选的WxPusher信息提供同意。未同意不提交；微信订阅通知拒绝不影响已同意的预约。
6. 在“我的—隐私与授权”撤回：本机顾客及员工登录清除，后续个人信息接口和微信身份调用被拦住，公开浏览可用。
7. 注销、删除、更正等通过页面公开电话联系运营者办理；本地撤回不等于服务器数据删除。服务端业务人员按政策处理申请及法定保存义务。

测试版上传后仍需由运营者核对平台隐私指引、体验账号及实际服务，再提交审核。审核结果以微信平台为准。
