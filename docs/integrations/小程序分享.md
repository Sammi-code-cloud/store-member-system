# 小程序分享

首页和茶室预订页提供微信好友分享按钮，右上角菜单支持好友和朋友圈分享。
好友卡片分别进入首页或茶室预订页，朋友圈使用当前页面；两者都只携带公开的 `storeId`。
接收方加载营业分店列表后选择对应门店；门店已停用或不存在时，沿用页面的首家营业分店回退逻辑。

分享使用固定门店图片 `/static/share-logo.png`，避免默认页面截图包含余额、联系人或预约信息。
链接不携带登录凭证、会员身份、付款码、扫码授权参数或已选预约时间。接收方使用自己的账号预约。

实现使用 uni-app 官方分享生命周期及 `button open-type="share"`：https://uniapp.dcloud.net.cn/share

验证：`node --test bama-store-miniapp/scripts/customer-share.test.mjs`，并编译微信小程序检查页面分享配置、按钮、处理函数和图片资源。
真机验收：分享两个页面到好友及朋友圈，接收方核对分店、访客浏览及登录后的预约操作。
