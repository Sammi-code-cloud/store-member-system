# 首次微信绑定短信验证

普通微信登录和后台会员二维码绑定统一要求短信验证。旧版小程序的 `manual-login`、`member-bind` 接口也不能仅凭手机号完成绑定。

首次返回 `bindRequired` 和五分钟绑定票据，小程序进入手机号验证页。阿里云模板为 `SMS_338475469`，内容为「您的验证码为：${code}，请勿泄露于他人！」，使用现有短信签名。

验证码六位、五分钟有效、60秒重发间隔，每个手机号及微信身份每日最多5次，错误尝试最多5次，成功后单次使用。验证码只保存哈希，不返回给客户端。

会员扫码核对后仍需验证同一手机号；短信验证成功后才关联会员。已有余额及记录保留。已经绑定微信的会员直接登录，无论是否存在历史短信验证记录，都不要求补验证码。只有未绑定微信的首次绑定需要短信验证。

服务端配置使用 `bama.sms` 下的 `enabled`、`access-key-id`、`access-key-secret`、`sign-name`、`template-code`。密钥仅放服务器私有配置；交易通知的 `wallet-notice` 独立保留。

验证覆盖：CustomerManualWechatTest、WechatIntegrationTest，以及小程序 customer-binding.test.mjs、manual-wechat-login.test.mjs。实际手机收码需用户点击获取验证码完成验收。
