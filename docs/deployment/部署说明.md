# 部署说明

本文仅包含通用流程；真实服务器、账号、备份位置与逐次发布记录保存在本机 `.local/operations/`。

## 配置

1. 从 `bama-store-admin/src/main/resources/application-local.yml.example` 准备私有环境配置，填写数据库参数、独立 JWT 密钥和微信参数。生产配置在代码仓库外保存，通过 Spring Boot 外部配置机制加载。
2. 构建管理后台时按实际部署路径设置 Vite 配置，反向代理将 API 请求转发到后端。
3. 在 `bama-store-miniapp` 执行 `node scripts/setup-local.mjs`，配置本地 `manifest.json` 的微信 AppID。将 `.env.example` 复制为 `.env.production.local` 并填写 API 域名。

## 发布与回滚

发布前使用 JDK 17 运行后端测试，执行前端测试和生产构建。先备份数据库与当前应用，确认数据库结构升级兼容性，再将验证过的构建产物放入新的版本目录，切换服务版本并检查健康状态、登录与关键业务接口。异常时恢复前一应用版本；数据库恢复须单独评估，避免覆盖新业务数据。

当前代码包含客户短信登录相关实现，不应仅凭构建成功覆盖一个尚未启用该能力的生产环境；必须先核对目标环境的配置和功能范围。已有服务器的具体发布流程见私有运维记录。

小程序上传后需在微信公众平台设置体验版；正式使用需通过审核并发布。员工绑定二维码的 `bama.wechat.staff-code-environment` 应与目标版本一致（体验版 `trial`、正式版 `release`）。上传、审核与正式发布是三个独立步骤。

所有地址使用自己的部署配置，例如 `https://admin.example.com`；不要在仓库中保存生产密码、证书私钥、数据库导出文件或真实用户数据。
